Why I chose IT

Ever since I was a kid, I had a passion for computers

Whenever my brother was assembling a pc, I was always closeby to look and ask which parts play which roles.

Then I got my dad's old raspberry pi 4 model b. Learning how to work with the linux command line,

I created a minecraft server that actually worked. (which for me was a huge win at the time.)

Then I discovered that running a server on a device that only has 1 gigabyte of RAM, isn't exactly optimal.

Luckily for me, the raspberry pi 5 was about to launch.

So for me, the most logical next step was to purchase one. So I got one with 8 gigabytes of RAM.

So having my own minecraft server felt amazing.

Some time later I wanted to make my own minecraft mod, even though i didn't have the coding experience needed for that.

So I used AI to generate the code for me, which rarely worked first try.

That only got worse when I wanted more and more features.
